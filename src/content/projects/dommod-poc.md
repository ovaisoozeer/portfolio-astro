I'm working on a proper app for guided domain modelling. This is a small app I use to demonstrate the principles of creating chains of events.

Users can create multiple, compare them, see highlighted conflicts and add additional metadata.

Once complete, they can export their map to JSON for use downstream.

It runs entirely on the client's browser and uses localstorage.
